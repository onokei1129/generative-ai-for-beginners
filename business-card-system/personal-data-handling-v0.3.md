# 名刺一元管理システム 個人情報の取扱い

**Ver.0.3 草案（法務／総務レビュー用）**

論点M への対応として、要件定義書 Ver.0.3 に追加する章の草案。

> **この文書は法的な助言ではない。** 条文の解釈と、自社の規程・プライバシーポリシーとの
> 整合は、必ず法務／総務の確認を受けること。本書の役割は、**確認すべき論点を漏らさず並べ、
> 「システムで既に手当てできていること」と「運用・規程で決めるべきこと」を分けて示す**ことにある。
> 参照した条番号は個人情報の保護に関する法律（以下「法」）のもの。

---

## 1. 前提の整理

| 事項 | 整理 |
| --- | --- |
| 名刺の記載事項は個人情報か | **該当する。** 氏名により特定の個人を識別できる（法2条1項） |
| 本システムに蓄積されたものは | **個人データ**（検索できるよう体系的に構成した個人情報データベース等を構成する。法16条3項） |
| 開示等請求の対象か | **保有個人データに該当する**前提で設計する（法16条4項） |
| 要配慮個人情報を含むか | 通常は含まない。ただし**業種によっては役職・所属から推知される場合がある**ため、運用で確認する |

名刺は「相手方から受け取ったもの」だが、**受け取った時点で本人の同意があるとは限らない**。
取得の場面（対面での交換、展示会での回収、第三者からの一括受領）によって扱いが変わりうるため、
**5章の確認事項**として整理した。

## 2. 利用目的（法17条・21条）

### 2.1 特定する利用目的（案）

> 当社は、名刺情報を次の目的で利用します。
> 1. 取引先・見込み先との連絡および商談の実施
> 2. 社内における取引先情報の共有と重複管理の防止
> 3. 当社の商品・サービスに関する営業活動および案内の送付
> 4. 上記に付随する社内管理業務

**3（案内の送付）を含めるかは業務判断。** 含める場合はプライバシーポリシーへの記載が必要で、
特定電子メール法上のオプトイン規制（広告宣伝メールを送る場合）も別途かかる。

### 2.2 本人への通知・公表

名刺交換の場で口頭の通知は現実的でないため、**自社ウェブサイトのプライバシーポリシーで公表**する
方法を想定する（法21条1項）。**ポリシーの改訂要否を法務に確認すること。**

## 3. 安全管理措置（法23条）

ガイドラインの4区分で整理する。**「実装済み」はシステムで機械的に担保されるもの、
「運用で決める」は規程・体制で担保するもの。**

### 3.1 組織的安全管理措置

| 措置 | 状態 |
| --- | --- |
| 取扱責任者・取扱者の範囲の明確化 | **運用で決める**（システム上は利用者管理・権限で表現できる） |
| 取扱状況の記録と点検 | **実装済み** — 監査ログ・変更履歴・CSV出力ログ・ログイン履歴を記録し、管理画面から照会できる |
| 漏えい時の報告体制 | **運用で決める**（4章参照） |

### 3.2 人的安全管理措置

| 措置 | 状態 |
| --- | --- |
| 従業者への教育 | **運用で決める** |
| 秘密保持義務 | **運用で決める**（就業規則・誓約書） |
| 持出しの抑止 | **一部実装済み** — CSV出力に出力者・日時・管理番号・注意表示を付与し、出力ログを全件記録する。ファイル名にも管理番号が入るため、出回ったファイルから出力者を追跡できる |

### 3.3 物理的安全管理措置

| 措置 | 状態 |
| --- | --- |
| 機器・電子媒体の盗難防止 | **運用で決める**（クラウド事業者の責任範囲は論点Bの決定に依存） |
| 電子媒体の持ち運び時の保護 | **運用で決める** — バックアップ媒体を社外保管する場合の取扱いを定める |

### 3.4 技術的安全管理措置

| 措置 | 状態 |
| --- | --- |
| アクセス制御 | **実装済み** — ログイン必須、管理機能は管理者のみ、IPアドレス制限、管理者の社外アクセス個別許可 |
| アクセス者の識別と認証 | **実装済み** — PBKDF2によるパスワード保存、TOTP多要素認証、ログイン失敗の記録 |
| 不正アクセスの防止 | **実装済み** — CSRF対策、無操作自動ログアウト、起動時の危険設定チェック |
| 通信の暗号化 | **手順あり** — HTTPS前提。[運用手引き](./operations-guide.md)に設定手順を記載 |
| 保存時の暗号化 | **未実装。運用で決める** — DBおよび画像ストレージの保存時暗号化は、クラウド事業者の機能（例：ディスク暗号化、S3のサーバーサイド暗号化）に委ねる想定。**論点Bの決定後に設定として確定させる必要がある** |

> **保存時暗号化はシステム側で未対応の唯一の技術的措置。** 事業者機能で満たす前提だが、
> 「どの機能を有効にするか」を環境構築時に決めて記録する必要がある。

## 4. 漏えい等が発生した場合（法26条）

個人データの漏えい・滅失・毀損のうち、規則で定める事態に該当する場合は、
**個人情報保護委員会への報告と本人への通知が義務**となる。名刺情報では次が該当しうる。

| 該当しうる事態 | 例 |
| --- | --- |
| 不正の目的をもって行われたおそれがある漏えい等 | 不正アクセスによる名刺データの流出 |
| 1,000人を超える個人データの漏えい等 | 全件CSVの誤送信・紛失 |

報告は**速報と確報の2段階**（速報は速やかに、確報は原則30日以内。ただし不正の目的による
おそれがある場合は60日以内）。**具体の期限と手順は法務に確認のうえ、社内の報告様式に落とすこと。**

**システム側で用意できていること**：CSV出力ログに出力者・日時・件数・条件・出力項目・IP・端末が
残るため、「誰がいつ何件出したか」を事後に特定できる。監査ログのアーカイブは3年分保持する。

## 5. 決定が必要な事項

法務／総務との確認事項。**いずれも本システムの実装ではなく、規程・運用の決定を要する。**

| # | 確認事項 | 影響 |
| --- | --- | --- |
| 1 | プライバシーポリシーに名刺情報の利用目的を記載済みか。改訂が必要か | 2章の文言が確定する |
| 2 | 営業案内の送付（2.1の目的3）を利用目的に含めてよいか | 含めない場合、システム上の用途も限定される |
| 3 | **クラウドOCRを利用する場合、外部送信は「委託」に当たるとの整理でよいか**（法25条の委託先監督義務） | **論点Cの前提。整理次第でサービス選定が変わる** |
| 4 | 3の事業者のデータ処理地が国外の場合、法28条（外国にある第三者への提供）の手当てが必要か | 同上。**同意取得が必要となる場合、実務上クラウドOCRは選べない** |
| 5 | 保有個人データの開示・訂正・利用停止請求を受けた場合の窓口と手順 | 6章参照 |
| 6 | 保存時暗号化を事業者のどの機能で満たすか | 3.4の未実装項目が閉じる |
| 7 | 名刺の取得経路（対面交換以外）に制約を設けるか | 第三者から一括で受領した名刺の取扱い |
| 8 | 退職者が取得した名刺を保持し続けてよいか | 要件§10は保存期限を設けない方針。**論点Nで実装した「退職者の未確認データの引き継ぎ」とあわせて確認** |

> **3と4は論点C（OCRサービスの選定）の前提条件。** 精度の測定より前に決着していないと、
> 精度が良くても採用できないという結果になりうる。**先に確認することを勧める。**

## 6. 開示等請求への対応（法33条〜35条）

名刺の本人から開示・訂正・利用停止を求められた場合の想定手順。

| 請求 | 対応 | システムでできること |
| --- | --- | --- |
| 開示 | 該当人物の登録内容を出力して回答 | **可能** — 人物の詳細画面と、対象を絞ったCSV出力 |
| 訂正・追加・削除 | 内容を修正 | **可能** — 編集機能。変更前後・変更者・理由が履歴に残る |
| 利用停止・消去 | 該当データを削除 | **可能** — 名刺の削除（論理削除）と完全削除（purge）。完全削除は管理者のみ |

**窓口・本人確認の方法・回答期限は運用で定める必要がある。** システムは「求められた操作を
実行し、実行した事実を記録する」ところまでを担う。

> 削除の際、**変更履歴は無期限保持の方針（論点H）である点に注意。** 履歴には変更前の値が
> 含まれるため、利用停止請求に応じて完全削除する場合、**履歴側の扱いを決めておく必要がある。**
> 現在の実装では完全削除（purge）で名刺と画像の実体を削除するが、
> **履歴レコードの削除範囲は運用判断として残っている。**

## 7. 保存期間

[論点H](./open-issues-v0.3.md#論点hログ履歴の保存期間) で決定した内容を再掲する。

| 対象 | 期間 |
| --- | --- |
| 名刺データ | 期限を設けない（要件§10） |
| 変更履歴 | 無期限 |
| 監査ログ・CSV出力ログ・ログイン履歴 | 1年でアーカイブ、3年で破棄 |

法は保存期間そのものを定めていないが、**利用目的の達成に必要な範囲を超えた保有は
避けるべきとされる（法22条：不要となったデータの消去の努力義務）。**
「取引が終了した相手の名刺を無期限に保持してよいか」は**確認事項#7・#8とあわせて判断すること。**

# Windows 用の起動ファイル

コマンドを打たずに、ダブルクリックで操作するためのバッチファイルです。

## はじめに

`create-desktop-shortcuts.bat` をダブルクリックすると、デスクトップに
**デスクトップに直接**、次の7つのショートカットが並びます。
すべて `名刺 ` で始まるので、名前順に並べるとまとまって表示されます。

| ショートカット | 内容 | tesseract |
| --- | --- | --- |
| 名刺 1 準備する（更新とセットアップ） | `git pull` → ショートカット作り直し → 実行環境の用意 | 不要 |
| 名刺 2 名刺を仕分ける | スキャンフォルダから名刺だけを取り出し、**結果のフォルダまで開く** | **必要** |
| 名刺 3 ラベル入力 | 実名刺に正解ラベルを付ける | 不要 |
| 名刺 4 精度を測る | **進み具合を出してから**正答率を測り、`real-rule.md` に出す | **必要** |
| 名刺 アプリを起動 | 名刺管理システム本体を開く | **必要** |
| 名刺 この1枚を調べる | 画像をドラッグ＆ドロップして、判定の根拠とOCRの読み取り文字を見る | **必要** |
| 名刺 動かないとき（診断） | 環境の確認結果を出す | 不要 |

> **以前は「名刺システム」フォルダを作り、その中に入れていました。**
> 画面にはフォルダが1個見えるだけで分かりにくかったため、デスクトップへ
> 直接置く形に変えました。古いフォルダのショートカットは自動で片付けます
> （フォルダが空になれば消します。中に他のものが残っていれば触りません）。
>
> デスクトップを OneDrive や iCloud Drive で同期している場合に備え、
> 場所は Windows の設定から取得します。実行すると2行目に
> `デスクトップ: ...` と実際の場所が出るので、見当たらないときは
> その場所を直接開いて確認してください。

**続けて実行するものは1つにまとめてあります。**

- 更新のあとは必ずセットアップが要るので、**1** で両方行います
- 仕分けたら必ず結果を確認するので、**2** が結果のフォルダまで開きます
- 精度測定は元から進み具合の確認を含むので、専用の入口は置いていません

練習用（練習サンプルの生成・練習ラベル入力）はショートカットから外しました。
必要なら `windows` フォルダの `make-practice-samples.bat` /
`label-practice.bat` を直接実行できます。

**まず「名刺 1 準備する」を実行してください。** ここは tesseract が無くても動きます。
実際の名刺を扱う 2・4・アプリ起動では tesseract が必要です
（[インストーラ](https://github.com/UB-Mannheim/tesseract/wiki)。
導入時に **Japanese** と **Japanese (vertical)** を選ぶ）。

### 窓の開き方

作業が終わった画面は**自動で閉じます**（8秒後）。失敗したときだけ止まって
理由を出すので、そのまま読めます。

閉じない窓は2つだけです。どちらもサーバーを動かしているため、閉じると止まります。

- **名刺 3 ラベル入力**
- **名刺 アプリを起動**

> **番号を付け直したため、以前に作ったショートカットとは番号がずれています。**
> 「名刺 1 準備する」を1回押せば、古いショートカットを消して作り直します。
> 消すのは `名刺 ` で始まるものだけなので、ご自身で置いた他のショートカットや、
> 名刺の画像・ラベルには触れません。

## 更新のしかた

**2回目以降は「名刺 1 準備する」を押すだけです。** `git pull`・ショートカットの
作り直し・セットアップをまとめて行います。

はじめて更新するとき（まだショートカットが無いとき）だけ、手で取得します。

1. デスクトップ「名刺システム」の**どれかのショートカットを右クリック →
   「ファイルの場所を開く」**（`windows` フォルダが開きます）
2. エクスプローラの**アドレス欄**にパスを消して `cmd` と入力し Enter
3. 開いた画面で次の2行を実行

   ```
   cd ..\..
   git pull
   ```

4. `windows` フォルダの `create-desktop-shortcuts.bat` をダブルクリック

## 実名刺のテストの進め方

1回で終わらせる必要はありません。**3 と 4 を往復**しながら進めてください。

```
2 名刺を仕分ける ── 続けて「不明」フォルダが開くので、名刺なら1つ上へ移す
      ↓
3 ラベル入力 ←──────┐   黄色い欄（未確認）を画像と見比べて直す
      ↓              │
4 精度を測る ────────┘   残りがあればまた 3 へ
```

**「4 精度を測る」は、測る前に進み具合を出します。** あと何枚か・未確認の欄が
残っていないかが分かり、そのまま測るか選べます。迷ったらこれを実行してください。

目安は**30枚以上**。それ未満でも測れますが、数字が安定しません。

## 各ファイル

| ファイル | 対応するコマンド |
| --- | --- |
| `_check-tesseract.bat` | tesseract 本体と日本語データ（`jpn` / `jpn_vert`）の確認。他のバッチから `call` する |
| `update.bat` | `git pull` ＋ `create-desktop-shortcuts.bat` ＋ `setup.bat /quick`。実行中に自分自身が書き換わらないよう、一時フォルダへコピーしてから動く |
| `setup.bat` | `python -m venv .venv` ＋ `pip install -r requirements.txt` ＋ `pytest`（`/quick` で確認テストを省く。初回は必ず実行） |
| `make-practice-samples.bat` | `python -m poc.receipts --out .\poc\practice` |
| `label-practice.bat` | `python poc\label.py .\poc\practice` |
| `classify-scans.bat` | `python poc\classify.py <フォルダ> --copy-to .\poc\real-cards ...` ＋ `open-card-folder.bat /quiet` |
| `label-real-cards.bat` | `python poc\label.py .\poc\real-cards` |
| `open-card-folder.bat` | エクスプローラで名刺フォルダ（`unknown` を選んだ状態）と `sort.md` を開くだけ |
| `check-progress.bat` | `python -m poc.progress .\poc\real-cards` |
| `measure-accuracy.bat` | `python poc\runner.py --real .\poc\real-cards --out real-rule.md` |
| `run-app.bat` | `python -m uvicorn bcards.main:app --app-dir src` |

いずれも `app` フォルダへ移動してから実行するため、置き場所を変えないでください
（ショートカット経由なら問題ありません）。

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 「Python が見つかりません」 | [Python](https://www.python.org/downloads/windows/) を入れ直す。**Add python.exe to PATH** にチェック |
| 「セットアップがまだです」 | 先に「名刺 1 準備する」を実行する |
| 「tesseract が見つかりません」 | 下記「tesseract の入れ方」を参照。入れたあとは**画面を開き直す**（PATH の反映に必要） |
| 「日本語データ (jpn) がありません」 | 本体だけ入って言語データが入っていない状態。下記の手順2を参照 |
| インストーラで Windows が警告する | UB-Mannheim 版は**未署名**のため SmartScreen が「発行元不明」と出す。tesseract 公式wikiが案内している標準のWindows版 |
| 最初の言語選択に Japanese が無い | それは**インストーラの表示言語**の選択。English で進め、`Choose Components` で日本語データを選ぶ |
| 文字が化ける／`is not recognized as an internal or external command` | バッチが UTF-8 で保存されています。CP932 で保存し直してください（下記「文字コードについて」） |
| 画面がすぐ閉じる | ショートカットではなく `.bat` を直接ダブルクリックした場合に起きます。ショートカットから実行してください |
| ブラウザが開かない | 黒い画面に出ている URL（`http://127.0.0.1:8100/` など）を手で開いてください |
| 「名刺のフォルダがありません」 | 先に「名刺 2 名刺を仕分ける」を実行する |
| 精度が思ったより良い | 未確認の欄が残っている可能性があります。「4 精度を測る」の冒頭に出る進み具合で確認してください |
| 更新で「git が見つかりません」 | [Git for Windows](https://git-scm.com/download/win) を入れ、画面を開き直す |
| 更新できない（`local changes` 等） | 黒い画面で `git stash` を実行してから、もう一度「0」を押す。名刺の画像とラベルは git の管理外なので消えません |

黒い画面に出たエラーは、そのまま画面を撮って共有していただければ調べられます。

## tesseract の入れ方

[インストーラ](https://github.com/UB-Mannheim/tesseract/wiki)（`tesseract-ocr-w64-setup-*.exe`）を実行します。

**0. 最初に出る「Installer Language」は関係ありません**

起動直後に `Please select a language.`（Deutsch / English / Español ...）という小さな窓が出ますが、
これは**インストーラ自体の表示言語**で、OCRが読める言語とは別物です。**日本語は選べませんが正常**です。
`English` のまま OK で進めてください。

> **OCRの日本語データを選ぶのは、この先の `Choose Components` の画面です。**
> ここで探しても Japanese は見つかりません。

**1. PATH に入れる**

インストーラの序盤にある **`Add to PATH`** にチェックを入れます。
入れ忘れた場合は、`C:\Program Files\Tesseract-OCR` を環境変数 PATH に手で追加します。

**2. 日本語データを選ぶ（見落としやすい）**

**Choose Components** の画面で、**`Additional language data (download)` の左の `[+]` を押して展開**します。
**畳まれているため、展開しないと言語の一覧そのものが見えません。**「Japanese が見つからない」はほぼこれが原因です。

展開したらアルファベット順の長い一覧から次の2つにチェックします。

- **Japanese**
- **Japanese (vertical)** — 縦書きの名刺用

入れ忘れた場合は、**インストーラをもう一度実行して上書き**すれば追加できます。

**3. 確認**

新しくコマンド画面を開いて（PATH の反映に必要）:

```
tesseract --list-langs
```

一覧に `jpn` と `jpn_vert` があれば完了です。
「2 名刺を仕分ける」「4 精度を測る」も起動時に同じ確認を行い、
足りなければ入れ方を表示して止まります。

## 文字コードについて（編集する場合の注意）

バッチファイルは **CP932（Shift-JIS）＋ CRLF** で保存しています。

UTF-8 で保存すると、cmd.exe が日本語の途中で行を切ってしまい、
残りをコマンドとして解釈してエラーになります（`chcp 65001` を付けても起きます）。

```
[エラー] 練習用サンプルがありません。
'?」 を実行してください。' is not recognized as an internal or external command
```

編集するときは CP932 で保存できるエディタを使ってください。
リポジトリ側では `.gitattributes` で `*.bat -text` を指定し、
git がバイト列を変換しないようにしています（そのため diff は文字化けして見えます）。
